ברוכים הבאים ל-AI App Maker

התחברו עם חשבון Google כדי להתחיל לבנות, לערוך, לתרגם ולצנזר אפליקציות אנדרואיד.

היסטוריית שיחות

תארו אפליקציית אנדרואיד, ערכו, תרגמו או צנזרו APK קיים. Gemini עושה את החשיבה והכתיבה, GitHub Actions מקמפל וחותם APK אמיתי, והכל יורד אליכם ישירות מהדפדפן.

שיחה חדשה

אפשר להמשיך כאן את אותה אפליקציה — כל ההודעות נשמרות בחשבון שלכם.

עדיין אין הודעות. כתבו בקשת בנייה בתיבת התיאור למטה והתחילו שיחה.

חיבורים

המפתחות נשארים בזיכרון הדפדפן בלבד ונשלחים ישירות ל-Google ול-GitHub — הם לא נשמרים ולא עוברים דרך שרת שלישי.

מפתח אחד בכל שורה. כשיש כמה מפתחות, האתר מסובב ביניהם אוטומטית — כך המכסה החינמית של AI Studio מתחלקת בפועל בין כמה מפתחות, ואם מפתח נתקל במגבלת קצב (429) הבקשה עוברת אוטומטית למפתח הבא.

כתובת פרוקסי ל-Gemini (אופציונלי — לרשתות עם סינון תוכן)

בסביבות עם סינון תוכן כמו אתרוג או נטפרי, הפנייה הישירה מהדפדפן ל-generativelanguage.googleapis.com נחסמת לפעמים ברמת הרשת עצמה (לא קשור למפתחות או לקוד) — הפילטר מיירט את הבקשה ומחזיר עמוד חסימה במקום את התשובה האמיתית מ-Google. אם זה קורה אצלכם: הריצו את הפרוקסי החינמי המצורף (gemini-proxy-worker.js) כ-Cloudflare Worker משלכם, והדביקו כאן את כתובת ה-worker. שדה ריק = פנייה ישירה כרגיל, בלי שום שינוי בהתנהגות.

מחובר עם הרשאות פרו - המפתחות והריפו מנוהלים אוטומטית דרך השרת, אין צורך למלא כאן שום דבר.

מה בונים?

מסך יחיד, UI שנבנה בקוד (בלי קבצי layout) — כדי שהצנרת תישאר פשוטה ואמינה.

עמוק = Gemini "חושב" יותר לפני שהוא כותב קוד — איכות ומורכבות גבוהות יותר, אבל איטי יותר וצורך יותר קרדיטים. מהיר = מסך בסיסי, כמעט מיידי.

צנזור אפליקציה — תמונות

העלו APK קיים (למשל אפליקציה שכבר בניתם) כדי לראות את כל קבצי התמונות שבתוכו, ולהחליף או לצנזר (לרוקן) תמונות לא צנועות לפני העלאה לגוגל פליי. הסריקה והעריכה קורות כאן בדפדפן בלבד; ה-APK הערוך נשלח באמצעות ה-GitHub Token והריפו שמולאו למעלה ב"חיבורים" (לא צריך Gemini key לשלב הזה), כדי ש-GitHub Actions ייישר (zipalign) ויחתום (apksigner) אותו מחדש — בלי זה ה-APK לא יתקין, כי כל שינוי בקבצים מבטל את החתימה המקורית. מחיקת תמונה לא מסירה את הקובץ אלא מחליפה אותו בתמונה שקופה ריקה, כדי לא לשבור הפניות למשאב הזה בקוד של האפליקציה.

משתמשים

שינוי תפקיד, קרדיטים או חסימה נשמר מיד עם לחיצה על "שמור" באותה שורה.

כל השיחות

צפייה בכל שיחות המשתמשים, פתיחת תוכן מלא ומחיקת שיחה. הגישה זמינה למנהל בלבד.

מפתחות API למנויי פרו ופרו מקס

המפתחות נשמרים ב־Script Properties של ה־Apps Script, לא נשלחים למשתמשים ולא מוחזרים לדפדפן. שדה ריק משאיר את הערך הקיים ללא שינוי. כדי להחליף ערך, הזינו מפתחות/טוקן חדשים.

מחירים והוראות מערכת

עלות בקרדיטים לכל פעולה, ברירת המחדל למשתמש חדש, והוראות שיתווספו אוטומטית לכל פנייה ל-Gemini של משתמשי פרו ומעלה.

עריכת טקסטים באתר

כשמצב העריכה פעיל, כל טקסט מסומן (הכותרות, ההסברים והפוטר) הופך לניתן-לעריכה ישירות בעמוד - לוחצים על הטקסט, משנים, ולוחצים מחוץ לו כדי לשמור.

הצנרת מייצרת אפליקציית מסך-יחיד עם Activity אחד ואייקון וקטורי, ללא AndroidX וללא XML layouts — זה מה שמאפשר build בלי Gradle. ה-APK נחתם במפתח דיבאג זמני (JAR signing דרך keytool/jarsigner), טוב לבדיקות ולהתקנה ישירה על מכשיר, לא לפרסום בחנות. ה-APK מטאבים "צנזור אפליקציה", "עריכת אפליקציה" ו"תרגום אפליקציה" נחתם בנפרד עם apksigner, באותה שיטה בדיוק כמו הבנייה הרגילה: מפתח דיבאג חדש ואקראי בכל ריצה (לא keystore קבוע). המשמעות: כל APK שיוצא מהכלי הזה — מכל טאב — חתום במפתח שונה מכל APK קודם, כולל קודמים מהכלי הזה עצמו. להתקנה ראשונה זה לא משנה; אבל כדי להתקין גרסה חדשה מעל התקנה קיימת על אותו מכשיר (במקום למחוק ולהתקין מחדש ולאבד נתונים), חובה שיהיה אותו מפתח חתימה — כלומר עדכון-במקום לא יעבוד בין שתי הרצות של הכלי. לפרסום עם עדכונים עתידיים אמיתי (גוגל פליי או התקנה חוזרת על אותו מכשיר) צריך keystore קבוע ולשנות את workflow-י ה-sign כדי שישתמשו בו במקום ביצירת מפתח חדש בכל פעם — תגידו אם תרצו שאבנה את זה.
